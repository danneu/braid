# Plan: Capture paused-balance fixture after skip_balance remount

## Context

The balance status parser had a latent bug: glibc formats `0/0` as `-nan`, not `nan`. The parser only handled `nan% left`, silently suppressing the paused-balance warning after unlock. We fixed the parser, but there was no contract test against real VM output to catch this class of drift. The existing `capture-tool-fixtures` test captures idle balance status but not the paused-after-skip_balance variant.

## Goal

Capture the exact `btrfs balance status` output after a `skip_balance` remount in the fixture test, then add a Rust contract test that parses it. Future nixpkgs bumps that change the format will break `cargo test` immediately.

## Changes

### 1. `tests/capture-tool-fixtures.py` — add paused balance capture

Insert before the unmount/teardown section (before current line 109). Reuse the full proven pause recipe from `tests/cli/braid-unlock.py:225-288`:

1. Write 512MB data (`dd if=/dev/urandom bs=1M count=512`) — same as braid-unlock test
2. Bounded retry loop (3 attempts, alternating `single`/`raid1` targets):
   - Start balance in background, tight-loop pause (200 iterations, 0.02s sleep)
   - Check `btrfs balance status` — require `"paused"` in output AND `done < total` chunks (the `done < total` gate from braid-unlock.py:266 ensures real remaining work)
   - On failure: cancel balance, wait for "no balance", retry with opposite target
3. On success: unmount → remount with `skip_balance` → capture `btrfs balance status` stdout to fixture file
4. Cancel balance, remove extra data, remount normally for remaining teardown

Output file: `btrfs-balance-status-paused-skip-balance.txt`

### 2. `cli/tests/fixtures/nixos-25.11/btrfs-balance-status-paused-skip-balance.txt`

Generated by running `just capture-fixtures` after step 1. Committed as a golden file.

### 3. `cli/src/parse/btrfs_balance_status.rs` — add contract test

Add alongside the existing `balance_status_parses_nixos_25_11_*` tests:

```rust
#[test]
fn balance_status_parses_nixos_25_11_paused_skip_balance() {
    let raw = RawCommandOutput {
        cmd: "btrfs balance status".into(),
        stdout: fixture("btrfs-balance-status-paused-skip-balance.txt"),
        stderr: String::new(),
        exit_status: 1,
    };
    let out = parse_btrfs_balance_status(&raw).unwrap();
    // Assert full struct — catches any drift in counter/percentage formatting,
    // not just the enum variant.
    assert_eq!(
        out.state,
        BalanceState::Paused {
            done_chunks: 0,
            estimated_total_chunks: 0,
            considered_chunks: 0,
            pct_left: 0,
        }
    );
}
```

### 4. `tests/capture-tool-fixtures.nix` — bump disk sizes

Current: 2 x 512MB. RAID1 gives ~480MB usable after LUKS. Writing 512MB won't fit.
Change to: 2 x 1024MB (matches braid-unlock.nix disk sizes).
