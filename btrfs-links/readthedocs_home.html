Welcome to BTRFS documentation!

BTRFS is a modern copy on write (COW) filesystem for Linux aimed at implementing advanced features while also focusing on fault tolerance, repair and easy administration. You can read more about the features in the introduction or choose from the pages below. Documentation for command line tools btrfs(8), mkfs.btrfs(8) and others is in the manual pages.

Need help?

Assistance is available from the #btrfs channel on Libera Chat or the linux-btrfs mailing list. Issues with the userspace btrfs tools can be reported to the btrfs-progs issue tracker on GitHub.
